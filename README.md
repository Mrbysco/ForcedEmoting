# Forced Emoting #

## About ##
Forced Emoting adds the ability to force nearby humanoid entities to emote and while doing so they are unable to target (or move if configured).

By default, the mod comes with 2 emotes:
* wave - if "hello" or "hi" is said in chat
* cinema - if "cinema" is said in chat

By default, only cinema will immobilize an entity.

New emotes and triggers can be added through Resourcepack/Datapack combos.
